Sobre este sitio web

Para la creación de este sitio se utilizarón herramientas de desarrolo web estandar con el fin de mostrar los proyectos realizados durante la formación e ir documentando el proceso, agregando nuevos contenidos y manteneniendo el sitio actualizado.

Su diseño está basado en la plantilla proporcionada por UTEC.

Para la creación del código base se utilzó ChatGPT adjuntando una captura de pantalla de la plantilla proporcionada por UTEC y el siguiente prompt: Genera una estructura básica en html, css y javascript para crear un sitio web similar al de la imagen adjunta.
Posteriormente se realizaron modificaciones personales utilizando Visual Studio Code con el fin de adaptar el código base a las necesidades de la propuesta.

La base del sitio está construida con tres tecnologías principales:

  • HTML, que utilizo para organizar y estructurar los contenidos.
  • CSS, que permite darle al sitio su diseño, colores, tamaños y distribución.
  • JavaScript, que se encarga de agregar interactividad, como los menús desplegables.

También se incorporan algunos recursos complementarios, como Google Fonts para las tipografías y Material Icons para los iconos de la interfaz.

Elegí utilizar estas herramientas, porque me interesa el mundo del desarrolo web, he realizado alguna formación anteriormente y es una buena oportunidad para reconectar con ellas y su aplicación.
